# 决策准则卡：什么时候不该用主动学习（贝叶斯优化）

> 口径：强基线 = `farthest_point`（**最远点 max-min 空间填充**）；主动学习 = `gp_ucb`；命中 = 目标 top-10% 分位。
> 成本口径：**等成本（H1/H2 主口径）**；预算档 = 400。
> 效应量：**absolute gain (BO hits - baseline hits)**。不用相对增益，因为强基线自身的命中率跨任务摆动 3.68×（详见模块顶部注释），作分母会把基线运气放大成 BO 功劳；两者零点位置相同，绝对增益不受影响。
> 显著性：Wilcoxon 符号秩 + Holm–Bonferroni，α=0.05；效应量 Cliff's δ；区间为 bootstrap 2000 次 95% CI。

## 核心判据

- 在扫描区间 AUC ∈ [0.516, 0.931] 内**未观察到零点穿越**（任务数 18）
- bootstrap 中只有 2.9% 的重采样出现零点（57 / 2000 次）—— **这不足以支持『边界存在』的主张**，故不报 AUC\* 与 CI
- 绝对增益区间 = [+6.93, +130.13]（单位：预算内命中的候选个数），**全部为正**
- Holm 校正后**显著为正**的任务：**18 / 18**

**判据：本实验在扫描区间内未发现失效边界。**边界（若存在）位于 AUC 更低的区间，本扫描轴未覆盖到；按预注册 §9，此处如实报告，不修改题面。

## H4：合成可行性门控的影响（双向检验）

- 逐单元（任务 × 预算）策略排序反转率：38.5%（共 90 个单元）
- 单元内 Spearman 秩相关中位数：0.500
- 秩相关 < 1 的单元数：50
- `gp_ucb` 绝对增益的平均位移（门控 − 等成本）：-6.021

## 使用说明

1. 先估目标在**你的描述符集**下的可学习性（RF 交叉验证 ROC-AUC，标签 = 目标 top-10%）。
2. 在本实验覆盖的 AUC 区间内 BO 始终不劣于强基线；若目标可学习性进一步下降（AUC → 0.5），需自行用同法复核。
3. **不要**用「描述符–目标的皮尔逊/斯皮尔曼相关」做判据：实测在扫描轴上 r 仅从 0.08 变到 0.33，而 AUC 从 0.52 变到 0.93 —— 相关性几乎不区分可学与不可学，AUC 才能。
4. 若候选池含大量昂贵/难合成项，务必先看门控版结论（H4），成本结构本身会改写策略排序与你实际能做的实验次数。
5. 增益在小预算档（≤50）噪声很大（命中数本身是小数），以预算 400 档的结论为准。
