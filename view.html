4320 run 消融数据（144 单元 × 30 种子聚合）

文件 evidence_4320runs.csv 是 3 基底 × 6 表示 × 4 策略 × 2 门控 = 144 个消融单元的 聚合结果，每行对应一个单元在 30 个种子上的均值（n_hits_mean、 ttfh_mean）与合计（n_hits_sum、n_runs）。 144 × 30 = 4320 次 run 的全部信息由这 144 行承载，不另附逐 run 明细。

基底 dataset 表示 策略 门控 命中均值 命中合计 TTFH run 数
口径：命中 = 目标值落入该任务 top-10% 分位，随机期望恒为 0.100。TTFH = time-to-first-hit，首中所需采集轮数。 数据由 merge_runs.py 从 results/runs_*.jsonl 聚合，种子 20261015 固定、子种子由 blake2b 派生。
